## Что должно заработать

После расчёта DeepSeek пишет по-русски записку аналитика и пояснения к рисковым SKU. Числа берутся только из расчёта, выдуманные SKU вычищаются, без ключа дашборд собирается без записки. GitHub Actions пересчитывает ежедневно в 07:00 НСК, при пуше новых CSV и по кнопке; публикует Pages, коммитит историю и шлёт дайджест в Telegram. Скилл `/zakupki` в Claude Code пересчитывает и отвечает на вопросы закупщика. Есть инструкция и мастер для ввода секретов, есть README.
