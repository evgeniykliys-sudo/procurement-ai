Как устроено: все числа считает детерминированный Python — прогноз спроса с сезонностью, плечо поставки, товар в пути, надёжность поставщиков, отсечение по наценке. По каждому SKU система решает, что и сколько заказать, когда размещать следующий заказ, на сколько хватит запасов и где риск дефицита или излишка, и показывает расшифровку «почему столько».
ИИ (DeepSeek) получает уже посчитанные числа и пишет записку закупщику; количества он не меняет, а строки с числами не из расчёта отбрасываются. Claude Code — и среда разработки, и интерфейс закупщика через скилл /zakupki.
План пересчитывается в GitHub Actions каждое утро, при загрузке новых данных и по кнопке; после прогона дашборд обновляется на GitHub Pages и приходит дайджест в Telegram.
