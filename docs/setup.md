# Настройка: секреты, Telegram, GitHub Pages

Без секретов система работает: расчёт, дашборд и история есть, нет только записки ИИ-аналитика и дайджеста в Telegram. Ниже — как их включить. Значения секретов вы вводите сами с клавиатуры: они не появляются в истории команд, в выводе и в репозитории.

Понадобится: [GitHub CLI](https://cli.github.com) (`gh auth login` выполнен), `curl`, Python, Git Bash (на Windows).

## Быстро — мастер

Из корня репозитория:

```bash
bash scripts/setup_secrets.sh                  # репозиторий определится по git remote
bash scripts/setup_secrets.sh владелец/procurement-ai
```

Мастер проведёт по шагам ниже, запишет три секрета в GitHub, по желанию — в локальный `.env`, включит Pages и запустит первый расчёт.

## Вручную

### 1. Бот Telegram

1. Откройте в Telegram **@BotFather**, отправьте `/newbot`.
2. Задайте имя и логин бота (логин заканчивается на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AA…` — это `TELEGRAM_BOT_TOKEN`.

### 2. Chat id — куда слать дайджест

1. Откройте своего бота, нажмите «Запустить» и напишите ему любое сообщение. Для группы — добавьте бота в группу и напишите там.
2. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (подставьте токен) и найдите `"chat":{"id": …}` — это `TELEGRAM_CHAT_ID` (у групп число отрицательное). Мастер делает этот запрос сам и показывает только chat id.

### 3. Ключ DeepSeek

[platform.deepseek.com](https://platform.deepseek.com) → API keys → создать ключ (`sk-…`) — это `DEEPSEEK_API_KEY`. На балансе должны быть средства: один прогон — один запрос (повтор на тех же данных берётся из кеша).

### 4. Секреты GitHub

```bash
gh secret set TELEGRAM_BOT_TOKEN
gh secret set TELEGRAM_CHAT_ID
gh secret set DEEPSEEK_API_KEY
```

Каждая команда просит вставить значение — ввод не отображается. То же через сайт: **Settings → Secrets and variables → Actions → New repository secret**.

### 5. Локально — `.env`

```bash
cp .env.example .env    # и впишите значения после «=»
```

`SITE_URL` (необязательно) — адрес дашборда для ссылки в дайджесте при локальном `run --notify`. `.env` в `.gitignore` и в репозиторий не попадает. Программа читает переменные окружения, а если их нет — `.env` в текущей папке.

### 6. GitHub Pages

**Settings → Pages → Build and deployment → Source: GitHub Actions.** Адрес дашборда — `https://<владелец>.github.io/<репозиторий>/`; workflow сам подставляет его в дайджест.

### 7. Первый запуск

**Actions → «План закупок» → Run workflow** или:

```bash
gh workflow run plan.yml
gh run watch
```

Дальше расчёт идёт сам: каждый день в 00:00 UTC (07:00 по Новосибирску) и при каждом пуше новых CSV в `data/raw/`.

## Проверка

- В логе шага «Расчёт, сайт, дайджест» последняя строка: `записка ИИ: есть; дайджест: отправлен`.
- «записка ИИ: нет» — причина строкой выше («не задан ключ DEEPSEEK_API_KEY», «DeepSeek вернул ошибку HTTP 402 — закончился баланс» и т. п.); на дашборде на месте записки — «ИИ-записка недоступна: причина».
- «дайджест: нет» — строка «Дайджест в Telegram пропущен/не отправлен: …» с причиной. Частое: боту не написали ни одного сообщения, или chat id от другого чата.

## Замена и отзыв

- Новый токен бота: @BotFather → `/revoke` → снова `gh secret set TELEGRAM_BOT_TOKEN`.
- Новый ключ DeepSeek: создать в кабинете, старый удалить, `gh secret set DEEPSEEK_API_KEY`.
- Отключить дайджест — удалить секрет `TELEGRAM_BOT_TOKEN` (Settings → Secrets) — расчёт продолжит работать.
